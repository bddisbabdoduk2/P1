# 원단랭킹 제작 기획서
작성일: 2026-09-30
상태: 인터뷰 및 승인 내용 반영. 서비스 이름 미정. 디자인은 카드고릴라 레이아웃 기반 코랄 육아형으로 확정. 사이트 구현·공개 전 단계.

## 1. 목적과 대상
0~3세 아이의 옷과 피부에 닿는 제품을 구매하는 부모에게 근거 있는 원단 비교 정보를 제공한다.
초기 목표는 정보 신뢰성과 방문자 확보이며 수익 모델은 추후 결정한다.
국내외 논문, 공공기관 자료, 시험자료, 소비자 조사 등을 직접 조사한다. 아직 실제 원단·제품 순위는 확정하지 않았다.

## 2. 승인된 이용 흐름
원단 전체 또는 조건별 TOP 10 → 원단 상세 → 품목 선택 → 종합/가성비 제품 TOP 10 → 제품 상세 → 판매처 및 가격 확인.
순위는 최대 10개이며 자료가 충분한 후보가 적으면 확인된 수만 공개한다.
원단 순위 화면과 제품 순위 화면의 주된 행동은 정보 확인과 비교다.
제품 구매 링크는 제품 상세의 평가 내용 아래에 배치한다.
가능하면 공식몰과 다른 판매처를 함께 제공한다. 미확인 URL이나 실제로 없는 상품을 넣지 않는다.

## 3. 정보 범위
- 원단: 피부 자극 관련 근거, 통기성, 계절 적합성, 내구성, 가격 등.
- 비교 기능: 원단들을 나란히 비교하며 관리법은 비교표에서 제외.
- 관리법의 원단 상세 포함 여부: 이전 응답에서 제안한 해석이며 명시적으로 확정되지 않음.
- 상품: 국내 제품 중심. 내의·바디수트, 외출복, 속싸개, 수면조끼, 침구 등.
- 서로 용도가 다른 상품을 하나의 제품 순위로 섞지 않는다.
- 각 품목에 종합 순위와 가성비 순위를 따로 제공한다.

확정 시안: fabric-coral-final.html. 코랄 포인트, 부드러운 카드 모서리, 중앙 로고·2단 메뉴·넓은 배너·가로 바로가기·3열 차트를 유지한다.
이전에 검토한 다른 디자인은 폐기했으며 구현·수정 시 참고하거나 다시 적용하지 않는다.
서비스 이름과 정식 로고는 미정이다.
대부분의 정보는 비회원 공개. 커뮤니티 작성은 회원 중심으로 구현한다.
정보 페이지에 직접 달리는 원단/제품 후기는 후순위이며, 커뮤니티의 자유로운 경험 공유와 구분한다.

## 5. 평가 방법 설계안
아래는 구현을 위한 제안이며 실제 조사 후 확정한다.
- 원단 평가와 개별 제품 평가를 분리한다.
- 전체 순위는 평가한 조건의 범위를 설명하고, 모든 아기에게 같은 순위가 적용된다고 표현하지 않는다.
- 논문은 대상 연령, 대상자 수, 비교 대상, 원단·가공 사양, 결과, 한계를 기록한다.
- 영아 대상 직접 근거인지, 성인 또는 실험실 자료의 간접 근거인지 구분한다.
- 섬유 종류, 직조/편직 방식, 상표명을 같은 분류 수준으로 무분별하게 혼합하지 않는다.
- 원단 종류에 대한 연구 결과를 그 원단을 쓴 모든 상품의 검증 결과로 표시하지 않는다.
- 자료가 없는 항목은 '확인 필요'로 표시하고 0점 또는 임의 점수를 부여하지 않는다.
- 조사 전 점수와 가중치를 만들지 않는다. 공통 비교가 가능한 자료를 확보한 후 평가 방식을 공개한다.
- 종합 순위는 해당 품목의 소재·제품 사양과 근거를 바탕으로 산정한다.
- 가성비 순위는 같은 품목 및 비교 가능한 단위에서 가격과 확인된 사양을 함께 평가한다.
- 할인·배송비·묶음 수량·사이즈에 따른 가격 차이를 기록한다.
- 소비자 후기는 사용 경험으로 구분하며 임상 효과 또는 안전성의 증거로 대체하지 않는다.
- '아토피 치료', '무조건 안전' 등 자료가 뒷받침하지 않는 단정은 하지 않는다.

## 6. 신뢰와 판매처 운영
- 선정 이유와 단점을 함께 공개한다.
- 광고비·제휴 수수료가 편집 순위에 영향을 주지 않도록 한다.
- 제휴를 도입하면 수수료 발생 여부를 해당 링크 주변에 명시한다.
- 광고 영역은 편집 순위와 시각적으로 구분한다.
- 출처, 자료 발표일, 최근 확인일, 순위 변경 사유를 기록한다.
- 품절·판매 중단·링크 오류는 숨기지 않고 상태를 표시한다.
- 상품 이미지와 설명은 사용 가능한 자료를 확보하고 자체 요약을 사용한다.

## 7. 데이터 구조
- 원단: ID, 이름, 분류, 설명, 평가 항목, 관련 출처, 확인일.
- 출처: 원문 URL, 기관/저자, 제목, 발표일, 자료 유형, 적용 대상, 핵심 결과, 한계, 확인일.
- 제품: ID, 브랜드, 품목, 모델, 대상 연령/사이즈, 혼용률, 사양, 근거 URL, 확인 상태.
- 판매처: 제품 ID, 판매처명, URL, 가격, 배송비, 수량/단위, 재고 상태, 확인일, 제휴 여부.
- 순위: 원단/품목/조건, 종합 또는 가성비, 방법 버전, 근거, 순서, 발표일.
- 회원/커뮤니티: 계정, 닉네임, 글, 댓글, 신고, 운영 상태.
비밀번호와 소셜 로그인 인증정보는 공개 문서나 저장소에 저장하지 않는다.

## 8. 제작 순서
1. 승인된 요구사항과 화면 구조 기록.
2. 원단 자료 조사 및 근거 표 작성. 실제 조사 후 비교 가능한 원단 후보와 평가 기준 확정.
3. 국내 품목별 제품 후보 조사와 혼용률·가격·판매처 검증.
4. 확정된 코랄 육아형 디자인 적용. 서비스 이름은 추후 사용자 결정 반영.
5. 순위 → 비교 → 상세 → 판매처 흐름 구현.
6. 회원가입 및 커뮤니티 구현. 소셜 로그인은 서비스별 앱 설정과 인증 연결 검증 필요.
7. 모바일/PC 사용 흐름, 링크, 공개/회원 권한, 평가 출처 검증 후 공개.

## 9. 운영
GPT가 조사·정리·수정 업무를 최대한 수행한다.
주기적인 자동 수집·갱신은 아직 설정하지 않았으며, 갱신 주기와 실행 환경을 별도로 정한다.
외부 자료를 자동으로 공개 순위에 반영하기 전 자료 품질과 제품 동일성 검증 단계를 둔다.
커뮤니티는 글·댓글 작성과 함께 신고 및 운영자 숨김/삭제 기능을 갖추도록 설계한다.
