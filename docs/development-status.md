# 2026-10-01 개발 1차

## 기준

코랄 육아형 디자인, 우리 아이 상태에 맞는 원단 탐색, 육아톡톡, Next.js/Vercel/Supabase 운영 구조를 반영했습니다. 기존 HTML 미리보기 주소는 디자인 시안으로 유지하며 이 앱을 배포한 주소가 아닙니다.

## 확인한 사항

Next.js 빌드·TypeScript·ESLint, PostgreSQL(PGlite) migration/seed/RLS와 탐색 입력 테스트를 실행합니다. 실제 Supabase 프로젝트 목록은 비어 있어 DB에 연결하거나 원격 schema를 변경하지 않았습니다.

이 환경의 agent-browser daemon이 두 번 시작에 실패하여 실제 화면 검증은 완료하지 못했습니다. PC/모바일 Playwright 검사 코드는 CI에 포함했습니다. 결과가 통과하기 전 브라우저 QA 완료로 표현하지 않습니다.

## 공개 전 필수 작업

실제 개발 DB 설정 및 RLS advisors, 인증 메일/회원 글·댓글·신고 실사용, 운영자 권한, Vercel Preview, 이미지 권리, 원문·상품 표시사항 재검토를 완료해야 합니다. 수집 seed의 기본 상태는 draft입니다. 모든 후보가 안전하거나 아토피에 적합하다고 표시하지 않습니다.

## GitHub 동기화 상태

2026-10-01 대표님이 P1 공개 저장소 사용과 코드 업로드를 승인했습니다. GitHub 플러그인으로 P1의 읽기·쓰기 권한과 공개 상태를 확인했습니다. 개발 앱 소스와 운영 기술스택 문서를 공개 개발 브랜치로 동기화합니다. 비밀 키와 사용권 미확보 참고 사진은 업로드 대상에서 제외합니다. GitHub Actions에 PC/모바일 검증이 포함되어 있으며 실제 실행 결과는 별도로 확인합니다.
